# Design2Prompt ⚡

> **A visual, no-jargon website theme builder for vibe coders and AI-first developers.**
> Pick colors, typography, shapes, and moods visually—then export clean Markdown specifications, `.cursorrules`, `CLAUDE.md`, and Tailwind CSS tokens to paste directly into AI coding tools (Claude, Cursor, v0.dev, Bolt.new, Lovable).

## ✨ Features

- **Frontier AI & Tech Org Presets**:
  - 🏛️ **Anthropic Claude**: Warm linen cream, terracotta rust, deep espresso, and literary serif typography.
  - 🌌 **Google Antigravity / Gemini**: Deep cosmic obsidian, glowing cyan/indigo micro-borders, and agentic status indicators.
  - 🟢 **OpenAI / OpenCode**: Clean neutral dark zinc, signature AI emerald green, and distraction-free layout.
  - ▲ **Vercel / Geist**: Hyper-minimalist black & white, strict geometry, and sharp edges.
  - 🎯 **Linear / Raycast**: Slate 950 surfaces, inner specular highlights, Linear indigo/violet, and `kbd` shortcut chips.
  - 🔍 **Perplexity AI**: Deep mineral teal slate, ocean mint accents, and citation pill badges.
  - ⚡ **Supabase Studio**: Dark studio charcoal, acid neon green, and dense technical data displays.

- **Lifestyle & Creative Presets**:
  - 🎨 **Neo-Brutalism**: Thick 3px black borders, canary yellow, and hard unblurred drop shadows.
  - 🍸 **Editorial Luxury**: Haute couture warm parchment, champagne gold, and luxury serif typography.
  - 🌿 **Nordic Nature**: Earthy sage green, warm oatmeal, and gentle organic curves.
  - 🍬 **Playful Pastel Pop**: Bubblegum lavender, mint, bouncy pill buttons, and spring animations.
  - 📐 **Industrial Blueprint**: Utilitarian CAD blueprint navy, steel grays, and cadmium safety orange.

- **Target-Specific AI Prompt Wrappers**:
  - 📋 **Universal Markdown (`theme.md`)**: Complete human- and LLM-readable design token specification.
  - 💻 **Cursor / Windsurf (`.cursorrules`)**: Strict coding rule format instructing AI coders to adhere to exact variables and component patterns.
  - 🤖 **Claude / ChatGPT**: Tailored system prompt for frontend code generation.
  - ⚡ **v0.dev / Bolt.new / Lovable**: Structured prompt with Tailwind and Shadcn/UI conventions.
  - 🎨 **Tailwind CSS & CSS Variables**: Direct output of Tailwind v4 `@theme` and CSS `:root` custom properties.

- **Zero-Backend Sharing (`window.location.hash`)**:
  - Share your custom themes with anyone via a compressed URL hash. No server or database required!

- **Interactive Live Preview Playground**:
  - Interactive test triggers for live Toast notifications, Modal dialogs, and Form validation feedback.
  - Viewport switcher: Desktop (`1200px`), Tablet (`768px`), and Mobile (`375px`).
  - Colorblindness simulation filters: Protanopia, Deuteranopia, Tritanopia, and Monochrome.
  - WCAG AA / AAA contrast badge with **1-Click Auto-Fix Contrast** button.
  - **Vibe Roll 🎲**: One-click randomized harmonious style generator.

## 🚀 Getting Started

### Local Development

```bash
# Clone the repository
git clone git@github.com:devtint/design2prompt.git
cd design2prompt

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build for Production

```bash
npm run build
```

The static output is generated in `./dist` and ready for instant deployment to **GitHub Pages**, **Vercel**, or **Netlify** with zero configuration.
